# Connect Four Game

A web-based Connect Four game developed using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Interactive 7×6 game board
- Automatic turn switching
- Winner detection (horizontal, vertical, and diagonal)
- Restart game functionality
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Play
1. Two players take turns dropping discs into the columns.
2. The disc falls to the lowest available position.
3. The first player to connect four discs horizontally, vertically, or diagonally wins the game.

## Learning Outcomes
- DOM Manipulation
- Event Handling
- Game Logic Development
- Front-End Web Development
